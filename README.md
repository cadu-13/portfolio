# carreira.workflow

Portfólio de **Carlos Eduardo G. da Silva**, Analista Sênior de Dados e Automação em Finanças.

A página conta a trajetória como um workflow de automação: cada etapa da carreira é um nó executado em sequência (formação, experiências, stack, IA, impacto), com um personagem 3D que percorre o fluxo.

## Stack

- HTML, CSS e JavaScript puro, sem build
- [Three.js](https://threejs.org/) para o personagem 3D, com esqueleto e animações procedurais criados no próprio código
- Modelo 3D otimizado com [gltfpack](https://github.com/zeux/meshoptimizer) (de 25 MB para ~1,2 MB)

## Rodar localmente

```bash
python3 -m http.server 8000
```

Depois abra http://localhost:8000.
